
# Zerodha Clone

A full-stack stock trading platform inspired by Zerodha.

## Features

* User Authentication
* Dashboard for Portfolio Management
* Stock Watchlist
* Buy and Sell Interface
* Responsive User Interface

## Technologies Used

* React.js
* Node.js
* Express.js
* MongoDB
* HTML, CSS, JavaScript

## Installation

1. Clone the repository
2. Install dependencies
3. Start the frontend and backend servers

## Project Structure

* frontend/
* backend/
* dashboard/

* Trading history and reports
